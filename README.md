## 3. Чек-лист оформления ҚМЖ (Приказ №130 МОН РК)
1. Бөлім, педагогтің аты-жөні, күні, сыныбы, қатысушылар саны, сабақтың тақырыбы.
2. Оқу бағдарламасына сәйкес оқыту мақсаттары және нақты сабақ мақсаты.
3. Сабақ барысы: **Ұйымдастыру → Сабақтың ортасы → Бекіту → Рефлексия** (педагог әрекеті, оқушы әрекеті, бағалау, ресурстар).
4. Дескрипторлар мен қалыптастырушы бағалау (ҚБ) тапсырмалары.

## 4. Чек-лист оформления студенческой презентации (ВУЗы РК)
1. Формат экрана `16:9`, единая цветовая палитра (2–3 цвета), читаемый кегль (заголовок `24–32pt`, основной текст `16–20pt`).
2. Не более 40–60 слов на слайд: тезисы, таблицы и схемы вместо сплошного текста.
3. Обязательная структура: Титульный лист → План → Актуальность и цель → Основная часть → Выводы → Список литературы.
